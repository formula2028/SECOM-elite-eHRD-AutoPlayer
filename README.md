# SECOM-elite-eHRD-AutoPlayer
讓訊連eHRD系統能夠自動掛機查看影片,PDF,投影片 讓使用者能夠節省時間專心工作

本工具專為旭聯科技 (aEnrich) eHRD 數位學習平台設計，具備以下優勢：
1. 【全無頭模式 (Headless)】：瀏覽器完全在背景隱藏執行，不佔用螢幕、不彈出視窗干擾工作。
2. 【免安裝可攜式】：自帶 Python 核心，解壓縮即可使用，不需安裝 Python。
3. 【企業 EDR / 防毒友善】：完全不使用 PyInstaller 打包成未簽章 EXE，採用純原始碼執行，不會觸發 EDR 誤判攔截。
4. 【背景自然掛機】：模擬視窗焦點，即便無頭執行仍持續計時，真實播放完整時長並正常回傳時間。
5. 【人機協作接手】：最耗時的影片與簡報由程式自動跑完，完成後彈出系統提醒，並提供一鍵開啟瀏覽器接手作答。

【使用步驟】
1. 雙擊執行目錄中的【run.bat】開啟軟體介面。
2. 介面會自動在背景連線至 eHRD，並在介面上顯示【4 位驗證碼圖片】（若看不清可點「🔄 換一張」）。
3. 確認帳號、密碼無誤後，輸入驗證碼並點擊【登入系統】（或直接按 Enter）。
4. 登入成功後：
   - 系統會自動讀取您的「我的課程」清單。
   - 請在下拉選單選擇欲掛機的課程
5. 點擊【🚀 開始自動掛機】：
   - 程式會依序進入各章節，自動靜音播放。
   - 介面會實時顯示當前章節、進度條與累計秒數。
   - 時數達標後自動點擊【回傳時數並離開】並推進至下一單元。
6. 當全部影片教材播放完畢後：
   - 程式會彈出 Windows 系統提示框發出提醒。
   - 點擊介面上的【🌐 開啟瀏覽器接手作答】按鈕，系統將自動開啟瀏覽器並停留在測驗/問卷頁面供您作答。

-----------------------------------------------------------------------------
【常見問題與注意事項】

Q: 掛機期間我可以做其他工作嗎？
A: 可以！瀏覽器完全隱藏在背景執行，您打報告、瀏覽網頁、開會或看其他影片都不受任何干擾。
